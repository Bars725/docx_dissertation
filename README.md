# docx_dissertation

Настольная программа на Python для оформления диссертации в Word (.docx) по ГОСТ.
Сырой текст вставляется в отдельное окно без инструментов форматирования, а программа
сама применяет оформление нужного раздела: титульного листа, введения, главы,
подглавы, списка литературы или приложения.

* Пресеты: **ГОСТ 7.32-2017** (по умолчанию) и **ГОСТ Р 7.0.11-2011** (диссертация).
* Можно загрузить **образец .docx**: программа извлечёт поля, шрифты, интервалы,
  стили заголовков, формат нумерации, список литературы и колонтитулы и сохранит их как профиль.
* Всё оформление хранится в стилях Word, поэтому документ не «разваливается» при правке
  в Word или LibreOffice, а оглавление и навигация работают.
* Номера глав, подглав, источников и буквы приложений пересчитываются автоматически.
* **Работа со структурой**: выбор пункта слева показывает его заголовок и текст для правки
  («Сохранить изменения»); «＋ Добавить…» — новый элемент рядом с выбранным;
  ▲/▼ (Ctrl+↑/↓) — порядок, в том числе переход подглавы/пункта в соседнюю главу/подглаву;
  ◀/▶ (Ctrl+←/→) — уровень глава ↔ подглава ↔ пункт (вместе с вложенными);
  «Закрепить» — запрет перемещения пункта; «Удалить» (Delete). Номера пересчитываются.
* **Изображения**: «Добавить изображение…» — окно с папкой (кнопка «Обзор»), списком
  картинок, предпросмотром и подписью, закреплённой за файлом. «Вставить» ставит рисунок
  в текст у курсора; в документе он по центру, под ним — «Рисунок 1 – Название»
  (ГОСТ 7.32, п. 6.5), в приложениях — «Рисунок А.1». Размер — в пределах полей.
  «Ссылка на рисунок…» вставляет слово полностью, как требует ГОСТ («на рисунке 1»,
  «в соответствии с рисунком 2»; форма выбирается), номер обновляется сам.
* **Сложные элементы в тексте пункта** (таблицы, рисунки, формулы) показываются маркерами
  `⟦#1 Таблица⟧`: текст вокруг можно править, маркеры — переставлять или удалять.
  «Изменить принудительно» превращает списки Word и абзацы со сносками в обычный текст.
* **Порядок ГОСТ соблюдается всегда**: титульный лист → оглавление → введение → главы →
  заключение → список литературы → приложения (в том числе при открытии чужого документа).
* **Приложения** — список, как литература: буквы А, Б, В… (без Ё, З, Й, О, Ч, Ъ, Ы, Ь),
  порядок по упоминанию в тексте; ссылка `{@P2}` в тексте превращается в букву
  и обновляется при перестановке.
* **Живой предпросмотр** при вводе — с реальными номерами глав и источников и с указанием,
  куда будет вставлен фрагмент.
* **Титульный лист — форма** (организация, ФИО, тема, специальность, руководитель, город, год)
  по ГОСТ Р 7.0.11; при повторном открытии документа форма заполняется из него.
* **Оглавление** — обновляемое поле Word (номера страниц ставит Word при открытии / F9).
* **Список литературы** — таблица записей: добавление построчно, правка, перемещение,
  сортировка по алфавиту или по порядку упоминания. В тексте глав ссылки вставляются
  кнопкой «Ссылка на источник…» (`[@R3, с. 15]`) и **сами обновляют номер**, когда
  список расширяется или пересортировывается.

## Установка и запуск (Windows)

1. Python 3.10+ с python.org — с галочками «Add python.exe to PATH» и «tcl/tk and IDLE».
2. `install.bat` — создаст окружение `.venv` и поставит зависимости.
3. `run.bat` — запуск. `run.bat --check` — проверка, всего ли хватает.

Подробности, таблица зависимостей и решение ошибки
`No module named 'exceptions'` (конфликт со старым пакетом `docx`) — в
[docs/INSTALL.md](docs/INSTALL.md).

## Ссылки на литературу

В окне ввода текста ссылка записывается как `[@R3]`, `[@R3, с. 15]` или `[@R1; @R4]`
(R3 — ключ записи; удобнее вставлять кнопкой «Ссылка на источник…»). В документе это
становится `[3, с. 15]`, где номер — поле Word, привязанное к записи списка: после
сортировки или добавления источников номера во всём тексте пересчитываются.

## Командная строка

```bash
python -m dissertation inspect образец.docx                 # что извлекается из образца
python -m dissertation profile образец.docx -o профиль.json
python -m dissertation new диссертация.docx --preset gost-r-7.0.11-2011
python -m dissertation add диссертация.docx --type chapter --heading "Обзор литературы" --text-file глава1.txt
```

Типы блоков: `title_page`, `introduction`, `chapter`, `subchapter`, `section`, `body`,
`conclusion`, `bibliography`, `appendix`.

## Сборка .exe

```bash
pip install -r requirements-dev.txt
pyinstaller --onefile --windowed --name DissertationDocx --paths src run_app.py
```
