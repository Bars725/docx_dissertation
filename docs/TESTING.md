# Тестирование

## Автотесты

```bash
pip install -e .[dev]
pytest                      # все тесты
pytest -m "not libreoffice" # без LibreOffice
```

| `test_runs.py` | плейсхолдер в 3 runs, таблицы, колонтитулы, барьеры (таб, поле), закладки |
| `test_template_parser.py` | образец «как из Word», шрифты темы, roundtrip профиль → docx → профиль |
| `test_document_builder.py` | A4, шрифты во всех слотах, порядок схемы, позиции, перенумерация, чужие стили не меняются, атомарное сохранение |
| `test_bibliography.py` | ключи записей, ссылки `[@R3, с. 15]` → поля REF, сортировки, перемещение/удаление, «осиротевшие» ссылки |

| `test_envcheck.py` | распознавание конфликтующего пакета `docx` |
| `test_libreoffice_roundtrip.py` | пересохранение в LibreOffice → доработка → корректные номера; рендер PDF: число страниц |

## Матрица совместимости (ручная)

Для каждого источника: **(1)** `python -m dissertation inspect файл.docx` — отчёт осмыслен;
**(2)** открыть в программе, добавить главу и литературу, сохранить; **(3)** открыть
результат в Word и LibreOffice; **(4)** пересохранить там и снова доработать в программе.

| Источник образца | Что специфично | На что смотреть |
|---|---|---|
| Word 365/2019 (рус.) | локализованные имена стилей, шрифты темы, `w14`-разметка, латентные Heading 2–3 | шрифт в колонтитуле, номера глав, оглавление (F9) |
| Word со «старым» шаблоном вуза (.doc → .docx) | режим совместимости, прямое форматирование, многоуровневый список у Heading | нет двойных номеров, отчёт «нумерация списком Word» |
| LibreOffice Writer | styleId `Style5`…, `w:sdt` вокруг оглавления, свои имена колонтитулов | роли найдены по имени стилей, отступы |
| Google Docs (экспорт .docx) | нет пользовательских стилей, всё — прямое форматирование, интервал 1,15, поля 25,4 мм | профиль через взвешенную моду, новые стили ГОСТ созданы |
| Файл с таблицами/рисунками/сносками | `w:tbl`, `w:drawing`, `footnoteReference` | вставка после таблицы, абзацы с рисунками не повреждены |
| Документ с несколькими секциями (альбомные листы) | разные `sectPr`, связанные колонтитулы | нумерация страниц сквозная |

Удобно держать папку `samples/` с такими файлами (не в git, если там реальные
тексты) и прогонять её одной командой:

```bash
for f in samples/*.docx; do echo "== $f"; python -m dissertation inspect "$f"; done
```

## Ручной чек-лист GUI

- [ ] Главное меню: три кнопки; «Создание документа» → выбор ГОСТ/образца.
- [ ] Вставка из Word/браузера (Ctrl+V на **русской** раскладке), форматирование исходника не переносится.
- [ ] «Предпросмотр абзацев» показывает склейку переносов из PDF.
- [ ] Глава без заголовка → заголовком становится первая строка (с предупреждением).
- [ ] Вставка главы «после выбранного элемента» → номера последующих глав сдвинулись.
- [ ] Сохранение, пока файл открыт в Word → понятная ошибка, файл цел.
- [ ] «Открыть в Word» → оглавление/навигация видят Heading 1–3.
