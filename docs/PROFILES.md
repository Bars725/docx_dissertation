# Профили оформления: где лежат и как править вручную

## Где что хранится

| Что | Где | Можно править |
|---|---|---|
| Встроенные пресеты ГОСТ 7.32-2017 и ГОСТ Р 7.0.11-2011 | в коде: `src/dissertation/gost.py` | лучше не трогать — сохраните копию (ниже) |
| **Ваши профили** (копии пресетов, образцы, профили документов) | `%USERPROFILE%\.dissertation_docx\profiles\*.json`, например `C:\Users\<имя>\.dissertation_docx\profiles\` | **да** — обычный JSON в UTF-8 |
| Настройки (папка с картинками, подписи к ним, выбранные формы ссылок) | `%USERPROFILE%\.dissertation_docx\settings.json` | да |
| Оформление конкретного документа | стили внутри .docx: «ГОСТ Основной текст», «Heading 1–3», «ГОСТ Список литературы», «ГОСТ Рисунок», «ГОСТ Подпись рисунка» и др. | да — в Word: «Стили» → «Изменить» |

Меню **Файл → Профили оформления**:

* **Открыть папку профилей** — открывает папку в Проводнике;
* **Сохранить ГОСТ … как профиль для правки** — копия встроенного пресета в JSON;
* **Сохранить профиль текущего документа** — параметры, извлечённые из открытого документа.

После правки профиль появляется в «Создание документа» и в «Выбор документа →
Использовать профиль». Чтобы перенести правку в уже существующий документ:
«Выбор документа» → «Использовать профиль» → отметить «Привести стили и поля
документа к профилю».

Два способа точечной правки:

1. **JSON-профиль**, если правило должно действовать для всех будущих документов
   (поля, кегль, формат подписи и т. п.).
2. **Стиль в Word**, если правка нужна только в одном документе. Откройте документ в Word,
   измените стиль (например, «ГОСТ Основной текст»), сохраните. Программа при открытии
   берёт оформление из самого документа, новые фрагменты получат тот же стиль.
   Абзацы, вставленные программой, не содержат прямого форматирования, поэтому
   правка стиля меняет весь документ сразу.

Если в JSON допущена ошибка (лишняя запятая и т. п.), профиль просто не появится в
списке. Неизвестные поля игнорируются, отсутствующие берутся из ГОСТ.

## Поля профиля

### Страница — `page` (миллиметры)

```json
"page": {"width_mm": 210, "height_mm": 297,
         "margin_left_mm": 30, "margin_right_mm": 15, "margin_top_mm": 20, "margin_bottom_mm": 20,
         "header_distance_mm": 12.5, "footer_distance_mm": 12.5}
```

### Абзацы — блоки с одинаковым набором полей

`body` (основной текст), `title_page`, `structural_heading` (ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ…),
`chapter_heading`, `subchapter_heading`, `section_heading`, `bibliography`,
`appendix_heading` («ПРИЛОЖЕНИЕ А»), `appendix_title`, `figure` (абзац с рисунком),
`figure_caption` (подпись рисунка):

| Поле | Пример | Смысл |
|---|---|---|
| `font_name` | `"Times New Roman"` | шрифт |
| `font_size_pt` | `14` | кегль, пт |
| `bold` / `italic` / `all_caps` | `true` | полужирный / курсив / все прописные |
| `alignment` | `"justify"` | `left`, `center`, `right`, `justify` |
| `line_spacing` | `1.5` | межстрочный, множитель |
| `first_line_indent_cm` | `1.25` | абзацный отступ, см |
| `left_indent_cm` | `0` | отступ слева, см |
| `space_before_pt` / `space_after_pt` | `12` | интервал до/после, пт |
| `page_break_before` | `true` | с новой страницы |
| `keep_with_next` | `true` | не отрывать от следующего |
| `no_hyphenation` | `true` | запрет переносов (заголовки) |

### Нумерация и подписи

| Поле | Пример | Смысл |
|---|---|---|
| `numbering.enabled` | `true` | ставить номера в заголовках |
| `numbering.chapter` | `"{n} {title}"` или `"Глава {n}. {title}"` | формат главы |
| `numbering.subchapter` | `"{n}.{m} {title}"` | подглава |
| `numbering.section` | `"{n}.{m}.{k} {title}"` | пункт |
| `figure_caption_format` | `"Рисунок {n} – {title}"` | подпись рисунка (ГОСТ 7.32, п. 6.5) |
| `figure_numbering` | `"global"` или `"chapter"` | сквозная («Рисунок 5») или по главам («Рисунок 2.3»); в приложениях всегда «Рисунок А.1» |
| `bibliography_number_format` | `"{n}. "` | номер в списке литературы |
| `citation_separator` | `"; "` | разделитель в `[1; 2]` |
| `appendix_label` | `"ПРИЛОЖЕНИЕ {letter}"` | обозначение приложения |
| `appendix_letters` | `"АБВГДЕЖИКЛМНПРСТУФХЦШЩЭЮЯ"` | буквы приложений (без Ё, З, Й, О, Ч, Ъ, Ы, Ь) |

### Номера страниц — `page_numbering`

```json
"page_numbering": {"enabled": true, "position": "footer", "alignment": "center",
                   "hide_on_first_page": true}
```

`position`: `footer` (ГОСТ 7.32) или `header` (ГОСТ Р 7.0.11).

### Тексты структурных элементов

`introduction_title`, `conclusion_title`, `bibliography_title`, `toc_title`
(«СОДЕРЖАНИЕ»/«ОГЛАВЛЕНИЕ»), `structural_uppercase` (`true` — прописными), `toc_levels`
(сколько уровней заголовков в оглавлении), `language` (`"ru-RU"`), `auto_hyphenation`.

### Служебные поля

`name` — название в списках программы; `source`, `version`, `extraction_report` —
заполняются автоматически, их можно не трогать.

## Ссылки в тексте по ГОСТ

| На что | Как пишется в тексте | В окне ввода |
|---|---|---|
| источник | `[3]`, `[3, с. 15]`, `[1; 4]` | `[@R3, с. 15]` — кнопка «Ссылка на источник…» |
| рисунок | «на рисунке 2», «в соответствии с рисунком 2» — слово полностью (ГОСТ 7.32-2017; ГОСТ Р 2.105-2019, п. 6.9.3) | `рисунке {@F2}` — кнопка «Ссылка на рисунок…», форма слова выбирается |
| приложение | «в приложении А», «см. приложение Б» | `приложении {@P1}` — кнопка «Ссылка на приложение…» |

Квадратные скобки зарезервированы за ссылками на литературу. Сокращение «(рис. 2)»
предлагается как отдельный вариант: используйте его, только если это разрешают
методические указания вашего вуза.
